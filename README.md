# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
 1.Launch Software & Create File: Open Autodesk Fusion 360 and create a new design file, then select the create sketch icon from the toolbar.
 2.	Select Sketch Plane: Choose an appropriate construction plane (XY, YZ, or XZ plane) to start sketching.
 3.	Draw Initial Sketch Geometry: Utilize various sketching tools such as Line, Circle, Arc, Rectangle, and Polygon to construct the basic profile of the given drawing.

 Procedure For Creating The Component In Fusion 360:
 1. Start a new design:
    Open fusion 360 and create a new design. save the file with a suitable name so the work is not lost.
 2. Create the base sketch:
    Select create sketch and choose the XY plane. The XY plane is used as the main drawing plane for the component.
 3. Set the origin as the centre:
    Use the origin(0,0)as the Centre of the component. Draw horizontal and vertical construction lines through the origin. These lines help position the circular features symmetrically.
 4. Draw the central circular section:
    Select Center Diameter Circle and draw the concentric circles around the origin. Apply the radii shown in the drawing, such as R21, R32, and R40, using the sketch dimension tool. These circles form the central ring and guide the shape of the spokes.
 5. Mark the positions of the outer circular features:
    Use the dimensions in the drawing to locate the outer features relative to the origin. Add construction lines or point to mark their centres. The drawing shows features above, below, and on both sides of the central section.
 6. Draw the outer circles:
    Draw the circles at the marked positions using center diameter circle. apply the specified radii, including R15, R20, and R21, as shown in the drawing. use sketch dimension to set their sizes accurately.
 7. Connect the circular features:
    Use the Line, Arc, and Tangent Arc tools to connect the outer circles to the central section. shape the connecting edges to match the outline in the drawing. apply Tangent constraints wherever an arc joins a circle or line smoothly.
 8. Create the central spoke pattern:
    Draw the curved sections and opening inside the central ring to form the spoken pattern shown in the drawing. use arcs and trim away unwanted parts of the circles. if the design is symmetrical, create one section first and use sketch>mirror to make the matching section on the opposite side.
 9. Complete the outer profile:
     Add the remaining lines and arcs around the outside of the component. follow the drawing carefully so that all circular features are joined in the correct places.
 10. Trim extra sketch geometry:
     Select trim and remove the unnecessary portions of circles, arcs, and lines. keep only the edges needed to form the component's outline and internal openings.
 11. Apply dimension and constraints:
     Use sketch dimension to check the radii, distances, and positions against the drawing. add constraints such as coincident, tangent, horizontal, vertical, and symmetry where appropriate. these constraints help keep the sketch accurate and prevent the geometry from moving unexpectedly.
 12. Check the sketch profiles:
      Make sure the outer boundary and internal openings form closed profiles. if any profile is open, fusion 360 may not allow it to be extruded correctly. zoom in and check for gaps or overlapping lines.
 13. Finish the sketch:
      After checking the geometry and dimensions, select finish sketch to return to the 3D workspace.
 14. Review and save the model:
      Rotate the model to inspect its shape. confirm that the outer features, central ring, and openings have been created correctly. save the completed fusion 360 design.
